# Osmose

Le quiz rap du soir, français d'abord.

**[Jouer](https://amelienito.github.io/osmose/)**

On choisit sa partie (5, 10, 15 ou 20 questions), puis on joue contre la foule du soir. Les questions déjà vues ne reviennent qu'une fois qu'on a fait le tour.

## Ajouter ou corriger une question

Tout est dans `questions.js`, une ligne par question. Le mode d'emploi est en haut du fichier.

## Les fichiers

- `index.html` : le jeu
- `questions.js` : les questions
- `assets/` : les logos
- `maquettes/` : les pistes de design précédentes ([les voir](https://amelienito.github.io/osmose/maquettes/))

La foule et ses votes sont encore simulés.
